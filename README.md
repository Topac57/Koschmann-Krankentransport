# Koschmann Krankenfahrdienst

Vite-/React-Webseite des Krankenfahrdienstes Koschmann Ambulance in Essen.

## Entwicklung

```bash
npm install
npm run dev
```

## Qualitätsprüfung

```bash
npm run lint
npm run build
npm run preview
```

Für den Build sind keine Environment-Variablen erforderlich. Die eigenen Bilder und die Schriftart liegen unter `public/assets`. Die Einsatzgebietskarte lädt Kartenkacheln direkt von OpenStreetMap und weist die erforderliche Attribution aus.
